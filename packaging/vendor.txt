# Дополнительные библиотеки программы (подгружаются по требованию, см. src/py/02b_vendor.py).
#
# Правила:
#   * только чистый Python: колесо py3-none-any (одно на все ОС и архитектуры, без компиляции);
#   * точная версия и SHA256 колеса с PyPI — программа загрузит файл, только если хэш совпал байт в байт;
#   * ядро программы (портфель, импорт, налоги) не должно зависеть от этих библиотек: без них функция
#     показывает понятное сообщение, а остальное работает.
#
# Формат строки:  имя==версия  sha256  [python>=3.9]  [only_below=3.11]  [requires=имя,имя]
#   python>=X.Y      — минимальная версия Python; на более старом библиотека считается недоступной;
#   only_below=X.Y   — нужна только на Python ниже X.Y (бэкпорты вроде typing_extensions);
#   requires=…       — другие строки этого файла, которые надо загрузить вместе с ней.
#
# После правки:  python3 packaging/vendor_lock.py   (проверит колёса на PyPI и перепишет src/py/02a_vendor_lock.py)
#                python3 build.py
# При релизе:    python3 packaging/vendor_lock.py --download DIR  и  загрузить DIR/*.whl в релиз (запасной адрес).
