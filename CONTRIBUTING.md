# Участие в разработке

Приложение поставляется пользователям одним файлом `tinvest_analytics.py` (только стандартная библиотека Python 3.8+). Для удобства разработки исходники разбиты на части в `src/`, а итоговый файл собирается скриптом.

## Структура

```
src/py/NN_<имя>.py        фрагменты Python, склеиваются по порядку имён (не пакет, без импортов между ними;
                          поздние фрагменты используют глобальные имена ранних)
src/web/shell.html        каркас страницы с маркерами {{CSS}} и {{JS}}
src/web/css/NN_<имя>.css  стили по порядку имён
src/web/js/NN_<имя>.js    фрагменты JS по порядку имён (по одному на раздел/страницу)
build.py                  сборка -> tinvest_analytics.py
tinvest.py                лаунчер с автообновлением (скачивает релизный файл tinvest_analytics.py)
```

Страница (`PAGE`) собирается из `src/web/` и подставляется вместо маркера `{{PAGE}}` в `src/py/15_page.py`.

## Как вносить изменения

1. Правьте файлы в `src/`. **Никогда не правьте `tinvest_analytics.py` вручную**: он генерируется.
2. Выполните `python3 build.py` и закоммитьте и `src/`, и обновлённый `tinvest_analytics.py`.
3. `python3 build.py --check` завершается с ошибкой, если закоммиченный файл не совпадает со свежей сборкой (для CI и ревью).

Фрагменты склеиваются побайтово, без добавления символов, поэтому новый фрагмент нужно начинать и заканчивать с учётом переводов строк. Чтобы добавить фрагмент, создайте файл с нужным числовым префиксом.

## Локальный запуск

```
python3 tinvest_analytics.py --no-window --port 8799
```

Порт можно задать и переменной окружения `TINVEST_PORT`. Данные хранятся в `~/.tinvest_analytics` (можно переопределить через `TINVEST_HOME`); для отладки удобно указать отдельный каталог.

## Релизы

В релиз кладётся собранный одиночный файл `tinvest_analytics.py` и файл контрольных сумм `SHA256SUMS`. Имя ассета должно оставаться ровно `tinvest_analytics.py`: именно его скачивает лаунчер.
