# Библиотеки для серверных воркеров (на VPS, не в программе пользователя). Сейчас не нужна ни одна.
#
# Правила: точная версия и хэш каждого пакета, включая зависимости (pip install --require-hashes),
# только готовые колёса (--only-binary=:all:). Хэши удобно получить так:
#   pip download --only-binary=:all: --no-deps пакет==версия -d /tmp/w && pip hash /tmp/w/*.whl
#
# Ставятся в отдельное окружение /opt/tinvest-venv (см. server/README.md, «Библиотеки для серверных воркеров»);
# tinvest-update.sh доустанавливает их сам, когда этот файл меняется.
#
# Пример строки:
#   pypdf==6.21.4 --hash=sha256:33e4fb41ca352810eb4e9838aa0d82d6888a5f8bf682f43e99cce5faa666255c
