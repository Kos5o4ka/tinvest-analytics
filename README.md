# T-Invest Analytics

Локальная аналитика брокерских счетов Т-Инвестиций и отчётов других брокеров: портфель, доходность,
финансы и скоринг эмитентов по отчётности ФНС (РСБУ) и МСФО групп, список наблюдения с тревогами и уведомлениями в Telegram, календарь событий, первичка против вторички, зашифрованная резервная копия, экспорт в Excel, сравнение с индексами облигаций и фондами Мосбиржи, калькулятор инвестиций (реинвест, налоги и ИИС, инфляция, сценарии ставки), облигации (точная доходность с амортизациями, стресс-тест, риски дефолта и сценарии ключевой ставки, сигналы «дешевле аналогов» и замены, мониторинг и тревоги, решение по офертам, конструктор лесенки, реальная доходность и дюрационный разрыв, карточка облигации с аналогами, карта рынка, скринер, кредитные рейтинги, первичные размещения), выплаты по дням, ставки (КБД и ключевая), ребалансировка с учётом налога, комиссии и налоги по лотам (ЛДВ, ИИС, перенос убытков, сводка для 3-НДФЛ), учёт обменов бумаг (ГДР на акции, редомициляция) в истории и налогах. Меню по разделам, быстрый поиск Ctrl+K, режим «скрыть суммы» для скриншотов. Один файл, только стандартная библиотека Python 3.8+.

Не знаете, какой Mac: меню  → «Об этом Mac»; если в строке «Чип» написано Apple — берите Apple Silicon.

**macOS.** Распакуйте архив, перенесите «T-Invest Analytics» в «Программы» и откройте. Приложение не подписано сертификатом разработчика Apple,
поэтому при первом запуске система его заблокирует: откройте «Системные настройки → Конфиденциальность и безопасность», прокрутите вниз до сообщения
о «T-Invest Analytics» и нажмите **«Всё равно открыть»**. На более старых macOS достаточно щёлкнуть по приложению правой кнопкой и выбрать «Открыть».
Это нужно один раз. Есть отдельные сборки для Apple Silicon (M1–M4, `mac-arm64`) и для Intel (`mac-x64`), нужна macOS 11 или новее.
Если macOS пишет, что приложение «повреждено» или «не может быть проверено», снимите карантинную метку в Терминале:

```
xattr -dr com.apple.quarantine "/Applications/T-Invest Analytics.app"
```

**Windows.** Приложение тоже не подписано, поэтому SmartScreen покажет «Система Windows защитила ваш компьютер»: нажмите **«Подробнее → Выполнить в любом случае»**.

Программа обновляется сама: при каждом запуске показывает окно проверки обновлений и при необходимости скачивает новую версию (с проверкой контрольной суммы).
Скачанное приложение — это только запускалка, перекачивать его ради новых версий не нужно. Пока программа работает, остаётся небольшое окно
с кнопками «Открыть в браузере» и «Выйти»: закройте его, когда закончите.

Linux и для тех, кто предпочитает Python — см. «Установка через Python» ниже.

## Вход

При первом запуске программа попросит ключ доступа. Получить его можно в Telegram-боте [@tanalyticbot](https://t.me/tanalyticbot): напишите боту, он пришлёт ключ.
Ключ действует 24 часа; когда он истечёт, получите новый командой `/key` и вставьте его в программу.

Токен T-Invest API остаётся только на вашем компьютере: он не отправляется ни боту, ни серверу данных (подробности — в разделе «Приватность»).

## Установка через Python

1. Установите Python с [python.org](https://www.python.org/downloads/) (на Windows отметьте «Add Python to PATH»).
2. Скачайте один файл — [`tinvest.py`](tinvest.py) (кнопка «Raw» → «Сохранить как»).
3. Запустите:

   ```bash
   python3 tinvest.py
   ```

   На Windows: `python tinvest.py`.

При первом запуске лаунчер сам скачает последнюю версию программы, при каждом следующем проверит
наличие обновлений. Откроется окно приложения — вставьте API-токен в «Настройках».

Флаги: `--no-update` — не проверять обновления; `--no-gui` — без окна загрузки (прогресс в консоли; то же — переменная `TINVEST_NO_GUI=1`); `--no-window` — только сервер на `http://127.0.0.1:8765`.

## Токен нужен только для чтения

Создайте токен на странице [tbank.ru/invest/settings/api](https://www.tbank.ru/invest/settings/api/) (или в приложении: Профиль → Настройки → Токены T-Invest API) с правом **«только чтение»**. Токен показывается один раз — скопируйте его сразу. Торговые операции
приложение не выполняет.

## Приватность

- В репозитории **нет** токенов и личных данных — только код.
- Токен, база и кэш хранятся **только на вашем компьютере** в папке `~/.tinvest_analytics`
  (на Windows `C:\Users\<имя>\.tinvest_analytics`). Файл настроек создаётся с правами 0600.
- Токен отправляется только в API Т-Банка. Лаунчер токен не читает и никуда не передаёт.
- Рейтинги, КБД и ключевую ставку программа скачивает сама из публичных источников (канал @issuerRatings, сайты НКР, Эксперт РА, Мосбиржи и Банка России, отчётность компаний ГИР БО ФНС, календарь размещений investmint.ru). В эти запросы не попадают ни токен, ни состав портфеля (для отчётности передаются только ИНН эмитентов).
- Для эмитентов, которые сами листингованы или входят в листинговую группу, программа запрашивает публичную страницу smart-lab.ru с отчётностью МСФО по тикеру (передаётся только тикер акции, не чаще одного запроса в секунду; результат кэшируется на 7 дней).
- Уведомления в Telegram — только если вы сами подключите своего бота; сообщения проходят через серверы Telegram.
- Приложение слушает только `127.0.0.1` — из сети оно недоступно.

## Свой сервер данных (необязательно)

Публичные данные (Мосбиржа, ФНС, Банк России, рейтинги, МСФО) можно получать через общий кэширующий сервер, а не напрямую
с каждого компьютера: сервер ходит к источникам один раз и отдаёт ответы всем. Это быстрее и снижает нагрузку на источники.
Сервер — один файл на стандартной библиотеке Python, запускается локально или на VPS (в том числе за Cloudflare Tunnel).
Подробности, запуск и развёртывание: [server/README.md](server/README.md). Адрес и ключ задаются в «Настройках → Сервер данных»
(или переменными `TINVEST_DATA_SERVER`, `TINVEST_DATA_KEY`). Без настройки всё работает как раньше, напрямую.

**Что уходит на сервер данных:** только адреса запросов к публичным источникам, то есть ISIN, тикеры и ИНН бумаг и эмитентов,
которые вы открываете. Токен Т-Инвестиций, счета, позиции и операции на сервер не передаются: портфель всегда идёт напрямую в Т-Банк.

## Безопасность обновлений

- Лаунчер берёт только официальные релизы этого репозитория по HTTPS и только с доменов GitHub.
- Перед установкой проверяется SHA256 из файла `SHA256SUMS` в релизе; при несовпадении обновление отклоняется.
- Предыдущая версия остаётся рядом как `.bak`; без интернета запускается уже скачанная версия.
- Код открыт — вы можете прочитать всё, что запускается: `tinvest.py` короткий.
