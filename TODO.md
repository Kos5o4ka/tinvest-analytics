## ⚡ Производительность (см. `docs/PERFORMANCE_PLAN.md`)

### Ближайшие оптимизации (S)
- [x] **gzip-сжатие ответов сервера** (`server/tinvest_server.py` → `_send_json`) — сжатие крупных JSON (снэпшоты, котировки) в 5–8 раз
- [x] **ETag / 304 Not Modified** (`/v1/market/snapshot`, `/v1/proxy`) — в неторговое время 90%+ ответов возвращаются за 1–2 мс
- [x] **LRU-вытеснение вместо сброса `.clear()` в `_pcache`** — предотвращение массовых промахов при превышении 500 ключей
- [x] **SQLite `PRAGMA mmap_size=128МБ` + `cache_size=-32768`** — ускорение чтения дискового кэша сервера
- [x] **Прогрев hot-кэша при старте сервера** — предзагрузка снэпшотов, КБД, IMOEX, ключевой ставки

### Среднесрочные (M)
- [ ] **Перевод клиента на прямое чтение `/v1/market/snapshot`** при первичном входе на экраны карты/скринера (вместо 50 отдельных сетевых запросов)
- [x] **Параллельная сборка снэпшота** (`ThreadPoolExecutor` в `server/market_worker.py`)
- [x] **Метрики производительности в `/v1/health`** (`cache_hit_rate`, latency p50/p95)

### Архитектура
- [ ] **nginx перед сервером** (gzip + TLS offload + proxy_cache для снэпшота на 60 с)

## ✅ Полностью реализовано в ветке (готовность к релизу v0.31)

### Оболочка и платформа
- ✅ **Tauri v2 Shell**: sidecar архитектура (`--parent-pid`), нативный трей, frameless заголовок, single-instance
- ✅ **Релизный конвейер Tauri**: NSIS-инсталлятор Windows, DMG (x64 + arm64) macOS с Retina-фоном, `latest.json`, `tauri-plugin-updater`
- ✅ **Автопереезд (MIGRATE-1)**: миграция старых `pywebview` / Inno установок прямо из приложения с проверкой SHA256
- ✅ **Безопасность**: защита биометрией (Touch ID / Windows Hello) и PIN-кодом (PBKDF2), DPAPI-шифрование на Windows, автоблокировка (по умолчанию отключена)

### Синхронизация и Telegram-бот
- ✅ **Авторизация**: вход в один клик по 4-значному коду с проверкой verifier
- ✅ **Привязка к Telegram-аккаунту**: тревоги, личные тихие часы, очередь сделок и облачные копии привязаны к `tg_id`, а не к временному ключу
- ✅ **Обнаружение копии**: при подключении второго устройства сразу предлагается ввести фразу от имеющейся облачной копии
- ✅ **Бот 0.31**: интерактивное меню, экспресс-скринеры (`/top_ofz`, `/top_corp`, `/floaters`), сравнение `A vs B`, пауза тревог, очередь сделок с телефона, чистый текст без эмодзи
- ✅ **Алерты**: серверный мониторинг раскрытий и денежных потоков, тихие часы, фильтрация по `min_severity`

### Аналитика и финансовая логика
- ✅ **Сплиты в налогах**: учёт сплитов (`T`, `TRNFP`) в налоговых лотах FIFO и ЛДВ
